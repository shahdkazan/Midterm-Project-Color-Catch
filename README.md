# Midterm-Project-Color-Catch
Project Description

Color Catch is a 3D Unity game where the player collects colored tomatoes while avoiding wrong colors, bombs, and a chasing crow enemy. The goal is to score as many points as possible before the timer runs out.

Features

3D Environment: Imported scene with boundaries to contain the player.

Player: Moves using WASD or arrow keys.

Collectibles:

Tomatoes with random colors. Collect the target color to gain points.

Wrong colors reduce points.

Bombs push the player and reduce score by 10.

AI Enemy: Crow that chases the player using NavMesh pathfinding.

Score & Timer: Tracks points and counts down from a set time.

UI: Shows score, timer, and target color. Game Over screen appears when time runs out.

Audio: Background music and sound effects for actions.

How to Play

Move with WASD or arrow keys.

Collect tomatoes of the target color.

Avoid the crow and bombs.

Score as many points as possible before time ends.

Tools

Unity 3D

C# scripting

Unity NavMesh for AI

Assets from Unity Asset Store or Sketchfab
